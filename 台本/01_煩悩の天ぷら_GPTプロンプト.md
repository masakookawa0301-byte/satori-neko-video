# ChatGPT に渡すプロンプト（第1話「煩悩の天ぷら」）

## 使い方

1. ChatGPT で**新しいチャット**を開く
2. 下の「最初のメッセージ」に、参考画像を2枚添付して送る
   - `original-06.jpg`（三面図）
   - `original-05.jpg`（墨の画風）
3. 続けて **同じチャットで** ①を送る → できた絵をClaudeに見せる
4. OKなら、同じチャットで ②③④a を1枚ずつ送る
5. ④b は、④aの画像を選んで「編集」で送る（構図がそろう）

**ポイント**
- 1回に1枚ずつ頼む（まとめて頼むと絵がくずれやすい）
- 同じチャットで続けると、キャラクターがそろいやすい
- 9:16 にならないときは、2:3 の縦長でOK。動画では左右を少し切るので、**大事なものは中央寄り**に
- 気に入らないところは、同じチャットで「〜だけ直して。ほかは変えないで」と頼む

## 最初のメッセージ（参考画像2枚を添付して送る）

```
これから、オリジナルキャラクター「さとりねこ」の短いアニメ用の絵を、1枚ずつ5枚お願いします。まだ描かないで、このメッセージではルールだけ覚えてください。

【キャラクター】1枚目の画像（三面図）のさとりねこと同じキャラクター。
・丸く大きい頭、ふっくらした頬、短く丸い体、小さな丸い手
・淡い灰色〜生成り色の毛
・額に小さな白い丸
・穏やかに閉じた目（目は絶対に開けない）、眉あり、小さな鼻と口、左右にひげ
・首にくすんだ赤のよだれかけ
・下半身は地蔵のような丸い二山。尻尾なし
・服・数珠・アクセサリーはなし。人間の僧侶のようにしない

【画風】2枚目の画像のような、古い画譜の墨絵。
・墨線の太細とかすれ、薄墨、生成りの和紙の余白を広く
・淡い水彩は補助。赤いよだれかけを少しだけの差し色に
・猫の顔と体は、静かで広い色面
・紙目はごく薄く

【避けること】
点描、均一な粒子、砂目、顔や体の斑点・モザイク、全画面のノイズ、過剰な光・発光、3D、光沢、アニメ調、画像内の文字・ロゴ・落款・はんこ

【サイズ】縦長 9:16（無理なら 2:3 の縦長）。大事なものは画面の中央寄りに。

【煩悩】このお話に出てくる「煩悩」は、墨を一滴落としたような、黒〜濃い灰色の小さなもやもやした塊。顔・目・手足はなし。輪郭が少しにじむ。大きさは、さとりねこの手のひらに乗るくらい。

【湯気・油の泡】描かない（あとで動画で動かして足します）。

覚えたら「OK」とだけ返してください。
```

## ① 衣にくぐらせる（koromo）

```
1枚目をお願いします。
手元の寄り、やや上から見下ろす構図。木の台の上に、白いとろりとした天ぷらの衣が入った素朴な陶器の小鉢。さとりねこの丸い小さな手が、煩悩（墨のもやもやした塊）を衣にそっとくぐらせている。画面の上の方に、さとりねこの顎とよだれかけが少しだけ見える。まわりは生成りの余白を広く。
```

## ② 油にそっと入れる（ageru）

```
2枚目をお願いします。1枚目と同じさとりねこ・同じ画風で。
横向き（左向き）の中くらいの距離。古い日本の台所。かまどの上の黒い鉄鍋に油。さとりねこが小さな手で、白い衣をまとった煩悩を、油にそっと入れようとしている。背景の土壁と木の柱は薄墨で簡単に。画面の上3分の1は余白。湯気・油の泡は描かない。
```

## ③ 皿の天ぷらと合掌（gassho）

```
3枚目をお願いします。同じさとりねこ・同じ画風で。
引きの構図、正面やや上から。板の間に小さな丸い皿がひとつ、その上に揚がった天ぷらがひとつ（衣の中にうっすら墨色がのぞく）。皿の前でさとりねこが丸く座り、合掌して静かに目を閉じている。画面の上半分は大きな余白。さとりねこは画面のやや下。湯気は描かない。
```

## ④a かじる前（mae）

```
4枚目をお願いします。同じさとりねこ・同じ画風で。
顔の寄り、右向きの横顔。さとりねこが小さな手で持った天ぷらを、口元に近づけている。目は穏やかに閉じたまま、口は小さく少しだけ開く。背景は生成りの余白だけ。顔・よだれかけ・天ぷらで画面の中央から下を占める。
```

## ④b かじった後（ato）　※④aの画像を「編集」で

```
この画像を編集してください。構図・大きさ・位置・画風は全く変えずに、次の2点だけ変えてください。
・天ぷらを、ひと口かじって欠けた形にする
・さとりねこの頬をほんの少しふくらませ、満足そうな小さな口にする（目は閉じたまま、大げさに笑わせない）
```
