# アニメ制作ナレッジ（中割りで動かす方法）

第3話「煩悩クッキング きのこ鍋の巻」で確立した、さとりねこを「本当に動かす」ための手順と注意点。

## 全体の流れ

1. **絵コンテ**：16コマ程度。絵柄の基準は `素材/03_きのこ鍋/絵コンテ_高解像度.png`
2. **原画**：動かすカットごとに2〜3枚（動きの区切り：構え → 当たる → 結果）
3. **中割り**：Google Colab（無料T4 GPU）で ToonCrafter が原画の間を自動で描く
4. **タイミング**：中割りのコマから「どれを何コマ見せるか」を決めて並べ直す（`scripts/anime/retime_cut.py`）
5. **仕上げ**：効果音・BGM（`scripts/make_sounds.py`）を入れてつなぐ

## 原画（ChatGPT / Codex）

- **絵柄をそろえるには、satori-neko プロジェクト（Codex）で描かせる。** 普通のチャットだと参照画像が見えず、猫の顔や頭身が変わりやすい
- 指示に必ず入れること
  - 絵柄の基準：絵コンテ（高解像度）と三面図 06
  - 構図の基準：絵コンテの同じ番号のコマを、そのまま横長に大きくする
  - 同じカットの中では、構図・猫の位置と大きさ・背景・小物は完全に同じ。変えるのは指定した部分だけ
  - 横長1536×1024、文字・擬音・効果線・残像・枠線なし、1枚ずつ別の画像
- 原画は2枚だと差が大きすぎて中割りが崩れる。**3枚（構え・当たる瞬間・結果）が基本**
- 「切れる」「倒れる」などの変化は、それが起きた状態の原画を必ず入れる。入れないと包丁ときのこのタイミングがずれる

## 中割り（Colab・ToonCrafter）

- ノートブック：`scripts/anime/satorineko_nakawari_batch.ipynb`（フォルダごとまとめて処理）／`satorineko_nakawari_maker.ipynb`（1カットずつ）
- 必ず「ランタイム → T4 GPU」。①準備に5〜10分、1カット約2〜3分
- 出力は 512×320（ToonCrafterの仕様）
- 新しいComfyUIでは次の2つの修正が必要（ノートブックに反映済み）
  - 起動オプションに `--disable-dynamic-vram`
  - DynamiCrafterWrapper の `init_empty_weights() if is_accelerate_available` を `if False` に置き換え
- 中割りは途中で背景ごと少しずれることがある → タイミング付けのときに位置補正する

## タイミング（昔のアニメ風）

- 24fpsで考える。残像の重ね合わせは汚くなるので使わない（描かれたコマだけ使う）
- 例：⑨包丁で切る（約1.7秒）
  - 構え 14コマ → 振り下ろし3コマ → 当たる（サクッ）3コマ止め → 刃が通る3コマ → まな板に届く（トン）→ 18コマ止め
- 動いた後の状態は戻らない（切ったきのこは元に戻らない）ので、同じ動きのループはしない。繰り返すなら次の原画を足す

## やらないこと（失敗したこと）

- 1枚の絵をプログラムで揺らすだけ → 紙芝居っぽくなる
- 16コマが1枚にまとまった絵をそのまま使う → 1コマが小さくてぼやける
- 上下2ポーズの間を残像（重ね合わせ）でつなぐ → にじんで汚い
- 背景を固定して手だけ切り貼り → つぎはぎが目立つ
